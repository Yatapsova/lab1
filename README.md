# 2D Игра на Pygame

Проект по созданию небольшой 2D-игры с использованием графической библиотеки Pygame.

## Описание

Этот проект посвящен разработке 2D-игры, с которой можно взаимодействовать с помощью клавиатуры. Задача разделена на две части: обязательную и бонусную. Каждая из этих частей компилируется и выполняется отдельно.

## Особенности

### Обязательная часть:
- Движение игрока по карте (W/A/S/D или стрелки)
- Сбор коллекционных предметов
- Выход с уровня после сбора всех предметов
- Отображение количества ходов в консоли
- Выход по ESC или закрытию окна

### Бонусная часть (дополнительно):
- Добавлены патрули (X) на карте
- Проигрыш при столкновении с патрулем
- Анимация спрайтов и объектов
- Отображение количества ходов непосредственно на экране
- Улучшенная графика и HUD
